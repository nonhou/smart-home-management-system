# 接口设计

系统共 6 个数据接口，按用途分三类：数据采集、统计数据获取、设备控制。

## 一、数据采集接口

### 1. reportDeviceData — 设备数据上报

| 项 | 内容 |
| --- | --- |
| 协议 | HTTP POST / MQTT |
| 用途 | 设备定时上报运行数据，支持实时异常检测 |

请求：

```json
{
  "device_id": "light_001",
  "device_type": "light",
  "metric_type": "power",
  "metric_value": 120.5,
  "unit": "watt",
  "timestamp": "2024-01-15T10:30:00Z",
  "additional_data": { "voltage": 220, "current": 0.55 }
}
```

响应：

```json
{
  "code": 200,
  "message": "success",
  "data": { "record_id": "rec_123456" }
}
```

### 2. batchReportData — 批量数据上报

| 项 | 内容 |
| --- | --- |
| 协议 | HTTP POST |
| 用途 | 批量上报数据，降低网络开销 |

请求：

```json
{
  "device_id": "light_001",
  "batch_data": [
    { "metric_type": "power", "value": 120, "timestamp": "..." },
    { "metric_type": "temp", "value": 25.5, "timestamp": "..." }
  ]
}
```

响应：

```json
{
  "code": 200,
  "message": "success",
  "data": { "inserted": 2, "failed": 0 }
}
```

## 二、统计数据获取接口

### 3. subscribeDeviceMetrics — 实时数据订阅推送

| 项 | 内容 |
| --- | --- |
| 协议 | WebSocket / MQTT |
| 用途 | 实时数据订阅推送 |

请求：

```json
{
  "action": "subscribe",
  "device_ids": ["light_001", "ac_001"],
  "metric_types": ["power", "temperature"],
  "interval": 1000
}
```

推送：

```json
{
  "device_id": "light_001",
  "metric_type": "power",
  "value": 120.5,
  "timestamp": "..."
}
```

### 4. getLiveDashboardData — 仪表盘实时数据

| 项 | 内容 |
| --- | --- |
| 协议 | Server-Sent Events |
| 用途 | 仪表盘实时数据推送 |

响应：

```json
{
  "total_devices": 15,
  "online_devices": 12,
  "active_alerts": 3,
  "total_power": 4500.5,
  "alerts_by_type": {}
}
```

## 三、设备控制接口

### 5. controlDevice — 单设备控制

| 项 | 内容 |
| --- | --- |
| 协议 | HTTP PUT |
| 用途 | 控制单个设备的开关与参数 |

请求：

```json
{
  "device_id": "light_001",
  "action": "turn_on",
  "params": { "brightness": 80 },
  "source": "mobile_app",
  "request_id": "req_202401151030"
}
```

响应：

```json
{
  "code": 200,
  "message": "设备已开启",
  "data": {
    "device_id": "light_001",
    "new_state": "on",
    "executed_at": "2024-01-15T10:30:00Z"
  }
}
```

### 6. batchControlDevices — 批量设备控制

| 项 | 内容 |
| --- | --- |
| 协议 | HTTP POST |
| 用途 | 一次请求控制多台设备 |

请求：

```json
{
  "operations": [
    { "device_id": "light_001", "action": "turn_off" },
    { "device_id": "ac_001", "action": "set_temperature", "params": { "temp": 26 } }
  ]
}
```

响应：

```json
{
  "code": 200,
  "message": "批量操作执行完成",
  "data": { "success": 2, "failed": 0, "details": [] }
}
```

## 性能要求

| 操作 | 要求 |
| --- | --- |
| 单点控制 | 0.5 秒内响应 |
| 批量控制 | 1 秒内响应 |
| 实时电量监测 | 监测数据实时变化 |
| 小时 / 日 / 周 / 月统计 | 数据准确，统计及时 |

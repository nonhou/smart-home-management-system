# Power BI 报表搭建操作指引

从零到三页报表的完整点击步骤。配合 `README-powerbi.md`（建模说明与 DAX 清单）使用。

本机环境：Power BI Desktop 2.158（Store 版）、MySQL 8.0（服务名 `MySQL80`）。

---

## 前置：数据库准备

已完成，在新机器上重做时执行：

```bash
# 1. 建库建表 + 7 台设备
mysql -u root -p --default-character-set=utf8mb4 < sql/schema.sql

# 2. 造数脚本（建 tally 表与 8 个存储过程）
mysql -u root -p --default-character-set=utf8mb4 < sql/generate_history.sql

# 3. 生成 90 天历史数据 + 600 条报警
mysql -u root -p --default-character-set=utf8mb4 smart_home -e "CALL RebuildAll(90, 200);"
```

## 第 1 步 · 连接 MySQL

1. 打开 Power BI Desktop，点 **主页 → 获取数据 → 更多**
2. 左侧选 **数据库 → MySQL 数据库 → 连接**
3. 弹窗填写：

   | 字段 | 值 |
   | --- | --- |
   | 服务器 | `localhost:3306` |
   | 数据库 | `smart_home` |

   数据连接模式保持 **导入**（不要选 DirectQuery —— 5 万行数据太小，导入更快且时间智能函数全部可用）
4. 点确定，凭据窗口选 **数据库** 选项卡，用户名 `root`，密码填 MySQL 密码，连接
5. 导航器里**只勾选这三张表**：

   - `power_consumption`
   - `devices`
   - `alerts`

   四张统计表（`hourly_stats` / `daily_stats` / `weekly_stats` / `monthly_stats`）**不要勾**，理由见 `README-powerbi.md`

6. 点 **转换数据**（不要点「加载」），进入 Power Query 编辑器

> **报错「MySQL 连接器未安装」**：装 [mysql-connector-net-8.0.33.msi](https://dev.mysql.com/downloads/connector/net/8.0.html)，装完重启 Power BI Desktop。
>
> **报错「无法连接」**：先在命令行确认 `sc query MySQL80` 服务是 RUNNING。

## 第 2 步 · Power Query 清洗

### 2.1 `power_consumption` → `fact_power`

1. 右键左侧查询 `power_consumption` → **重命名** → `fact_power`
2. 选中 `id` 列 → 右键 → **删除列**
3. **添加列 → 自定义列**，新列名 `日期`，公式：

   ```
   Date.From([timestamp])
   ```

   类型改为 **日期**
4. **添加列 → 自定义列**，新列名 `小时`，公式：

   ```
   Time.Hour([timestamp])
   ```

   类型改为 **整数**

### 2.2 `devices` → `dim_device`

1. 重命名查询为 `dim_device`
2. 双击列头改中文名：

   | 原名 | 新名 |
   | --- | --- |
   | `device_id` | 设备编号 |
   | `device_name` | 设备名称 |
   | `device_type` | 设备类型 |
   | `power_rating` | 额定功率 |
   | `status` | 设备状态 |

3. 删除 `id`、`created_at`、`updated_at` 三列
4. **添加列 → 条件列**，新列名 `设备类型名称`：

   - 若 `设备类型` 等于 `light` 则输出 `照明`
   - 若 `设备类型` 等于 `fan` 则输出 `风扇`
   - 若 `设备类型` 等于 `ac` 则输出 `空调`
   - 否则 `其他`

### 2.3 `alerts` → `fact_alert`

1. 重命名查询为 `fact_alert`
2. `created_at` 重命名为 `创建时间`，类型设为 **日期/时间**
3. 删除 `id` 列
4. 添加自定义列 `日期`，公式 `Date.From([创建时间])`，类型 **日期**
5. **添加列 → 条件列** `报警类型`：

   - `high_power` → `超功率`
   - `device_fault` → `设备故障`
   - `unusual_pattern` → `异常用电模式`
   - 否则 `其他`

6. **添加列 → 条件列** `处理状态`：`active` → `活跃`，`resolved` → `已处理`

7. 点 **主页 → 关闭并应用**

> 中文列名和中文映射放在 Power Query 而不是 DAX 计算列，是为了让模型层保持干净，
> 且这些映射是静态的，不需要在 DAX 引擎里反复计算。

## 第 3 步 · 建立日期表

切到 **表格视图**（左侧第二个图标），点 **建模 → 新建表**，粘贴：

```dax
dim_date =
ADDCOLUMNS(
    CALENDAR(DATE(2026, 7, 1), DATE(2026, 9, 30)),
    "年", YEAR([Date]),
    "月", FORMAT([Date], "YYYY-MM"),
    "月序号", MONTH([Date]),
    "日", DAY([Date]),
    "星期", FORMAT([Date], "aaaa"),
    "星期序号", WEEKDAY([Date], 2),
    "是否周末", IF(WEEKDAY([Date], 2) >= 6, "周末", "工作日")
)
```

选中 `dim_date` 表 → **建模 → 标记为日期表** → 日期列选 `Date` → 确定。

> 日期范围要和 `power_consumption` 的实际数据范围一致。若改了造数天数，
> 用 `SELECT MIN(timestamp), MAX(timestamp) FROM power_consumption;` 查出来再改这两个日期。

## 第 4 步 · 建立关系

切到 **模型视图**，拖拽建立 4 条一对多关系：

| 一端 | 多端 | 说明 |
| --- | --- | --- |
| `dim_date[Date]` | `fact_power[日期]` | 用电的时间维度 |
| `dim_date[Date]` | `fact_alert[日期]` | 报警的时间维度 |
| `dim_device[设备编号]` | `fact_power[device_id]` | 用电的设备维度 |
| `dim_device[设备编号]` | `fact_alert[device_id]` | 报警的设备维度 |

四条都确认：**基数 `一对多`、交叉筛选方向 `单一`、状态 `活动`**。

## 第 5 步 · 计算列与度量值

### 5.1 事实表计算列

选中 `fact_power` → **建模 → 新建列**：

```dax
负载率 = DIVIDE(fact_power[power_usage], RELATED(dim_device[额定功率]) / 1000 * 0.25)
```

这条列把每条记录的用电量换算成该设备的负载率（0~1）。数据生成时已做 `LEAST(..., 1.00)`
截断，所以这一列**最大值必然 ≤ 1**，可以直接当校验用。

### 5.2 度量值

**建模 → 新建表**，只写一个表名占位：

```dax
_Measures = { BLANK() }
```

把下面所有度量值都建在这张 `_Measures` 表里（选中它 → 新建度量值）。
完整清单与逐条解释见 `README-powerbi.md`。

## 第 6 步 · 报表页

### 页 1 · 总览

| 位置 | 视觉对象 | 字段 |
| --- | --- | --- |
| 顶部 | 卡片 ×4 | 总用电量 / 日均用电 / 活跃报警 / 设备数 |
| 左中 | 折线图 | X = `dim_date[Date]`，Y = `总用电量` |
| 右上 | 环形图 | 图例 = `dim_device[设备类型名称]`，值 = `总用电量` |
| 右下 | 条形图 | Y = `dim_device[设备名称]`，X = `总用电量`，筛选 Top 5 |
| 左上 | 切片器 | `dim_date[Date]`，样式选「介于」 |

### 页 2 · 用电趋势

| 位置 | 视觉对象 | 字段 |
| --- | --- | --- |
| 顶部 | 卡片 ×2 | 本月用电 / 用电量环比 |
| 中部 | 组合图（折线+柱形） | X = `dim_date[Date]`，列 Y = `总用电量`，行 Y = `记录条数` |
| 左中 | 矩阵 | 行 = `dim_date[星期]`，列 = `fact_power[小时]`，值 = `总用电量` |
| 右中 | 折线图 | X = `fact_power[小时]`，Y = `总用电量`，图例 = `dim_device[设备类型名称]` |
| 左上 | 切片器 | `dim_device[设备类型名称]`、`dim_date[是否周末]` |

矩阵热力做法：选中矩阵 → 格式 → 单元格元素 → 背景色 → 打开 → 按 `总用电量` 渐变。

### 页 3 · 设备与报警

| 位置 | 视觉对象 | 字段 |
| --- | --- | --- |
| 左 | 表格 | `设备名称` / `设备类型名称` / `额定功率` / `总用电量` / `记录条数` / `高负载时段占比` |
| 右上 | 散点图 | X = `额定功率`，Y = `总用电量`，详细信息 = `设备名称` |
| 右中 | 堆积柱形图 | X = `fact_alert[报警类型]`，Y = `报警总数`，图例 = `fact_alert[处理状态]` |
| 右下 | 折线图 | X = `dim_date[Date]`，Y = `报警总数` |
| 底部 | 表格 | `创建时间` / `设备名称` / `报警类型` / `报警内容` / `处理状态` |

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 连接时报「MySQL 连接器未安装」 | 装 mysql-connector-net-8.0.33.msi，重启 Power BI |
| 日期表标记失败 | `dim_date` 的 `Date` 列必须是日期类型且无重复值、无空值 |
| `DATEADD` 返回空 | 关系没建、或日期表没标记为日期表 |
| 度量值显示空白 | 检查关系方向，或 `fact_power[日期]` 是否成功建出 |
| 环形图里出现「其他」 | `dim_device[设备类型名称]` 的条件列没覆盖全，检查三个分支拼写 |
